🚢 捷淞进销存系统架构图

📋 项目概述

捷淞进销存系统是一个面向外贸企业的综合性 ERP 系统，涵盖采购、销售、库存、财务、海关报关、退税等全流程管理。

🏗️ 技术架构 前端后端

🎨 前端

Next.js 16 + React 19

TypeScript + Tailwind CSS

Zustand 状态管理

⚙️ 后端

Node.js + Express

Prisma ORM

JWT 认证

🗄️ 数据库

SQLite (开发)

PostgreSQL (生产)

🤖 AI

Kimi API 集成

智能助手

合同生成
