# 后端源码目录

> 若本文件夹结构或内容变化，请更新本文件。

## 目的

存放后端 API 所有源代码文件。

## 文件清单

| 文件/目录 | 地位 | 功能 |
|-----------|------|------|
| app.js | 入口 | Express 应用初始化和启动 |
| config/ | 配置层 | 环境变量和常量定义 |
| controllers/ | 控制层 | 处理 HTTP 请求，调用服务层 |
| middleware/ | 中间件层 | 认证、日志、错误处理 |
| routes/ | 路由层 | 定义 API 路由和参数验证 |
| services/ | 服务层 | 业务逻辑实现 |
| utils/ | 工具层 | 通用工具函数 |
