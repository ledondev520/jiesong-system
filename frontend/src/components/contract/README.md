# 合同附件组件

`ContractFiles.tsx` 保留采购/出口附件分类、上传、下载、删除和 PDF/图片预览。下载/预览通过共享 Axios 的无缓存二进制请求读取，再使用内存临时对象 URL，不依赖保持登录或把令牌放到链接里。手机操作按钮直接可见，桌面悬停或键盘聚焦可见。

共享 `lib/hooks/useContractFileAccess.ts` 在关闭、合同切换、认证失效/退出/重登录及卸载时取消请求、释放 URL，拒绝迟到响应和旧媒体错误。实际响应 MIME 仅允许 PDF 和普通栅格图片嵌入；浏览器显示失败有下载提示及重试。Word/Excel 仍下载后查看，后端角色校验继续决定文件是否可读。

`ContractFiles.test.tsx` 使用合成文件覆盖认证路径、重复下载、关闭/认证代次/卸载迟到成功与失败、URL 释放、真实错误重试、文件选择取消和上传失败保留旧附件。
