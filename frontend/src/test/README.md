## 目的/边界/职责
- 前端测试初始化与隔离夹具
- 真实接口夹具只允许合成资料和localhost
- 不继承生产配置、不查询凭据字段

## 文件清单
| 名字 | 地位 | 功能 |
|---|---|---|
| setup.ts | 初始化 | jsdom交互兼容与各测试清理 |
| account-name-fixture.ts | 真实接口夹具 | 启动私有名称服务、限制姓名写入、记录HTTP状态和独立安全字段读回 |

`account-name-fixture.ts` 只允许合成普通目标姓名更新，姓名之外的原值与空白密码在HTTP前检查；真实失败由私有SQLite触发器产生。没有业务响应mock或测试HTTP故障端点。
