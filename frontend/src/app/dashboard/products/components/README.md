# 商品档案组件

- `InventoryTab.tsx`：库存列表按当前分页/关键词实时读取服务端，单条及批量状态操作不复用旧缓存；保留请求序号保护，避免旧查询覆盖新筛选结果；批量操作结束只触发当前页/关键词刷新，不使用操作开始时的旧筛选
- `InventoryTab.lifecycle.test.tsx`：覆盖批量入库后刷新、待处理批量操作期间的搜索/翻页切换，以及验货后重新进入库存页面的即时显示
- 采购/验货来源库存由对应业务自动流转，页面不提供重复手工入出库入口

- `ProductDialog.tsx`：每次打开或切换商品建立独立编辑会话，关闭/ Escape 丢弃未保存内容；名称变化及会话结束让迟到的 HS 建议/详情失效，推荐选择以最新一次为准；保存期间冻结编辑并拦截重复提交，失败保留完整草稿可重试
- `ProductDialog.lifecycle.test.tsx`：重复关闭/重开、Escape 新增取消、编辑/新增切换、迟到手动匹配成功/失败、HS 详情与名称变化及乱序选择回归；所有 HS 请求均为合成 mock
- `ProductDialog.test.tsx`：保留原有名称匹配、推荐编码选择及税率/单位填充验收
