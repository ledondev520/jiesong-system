# UI Demo

> 若本文件夹结构或内容变化，请更新本文件。

## 简介
这是一个高保真UI演示原型，展示了捷淞进销存管理系统的设计风格和交互流程。

## 设计风格
- **风格**：现代简约，高级感
- **色调**：中性黑灰主调，搭配功能性强调色
- **布局**：Notion风格左侧边栏，卡片式内容区
- **技术**：纯HTML/CSS/JS，无框架依赖

## 包含页面
1. **登录页**：简洁的登录界面
2. **Dashboard**：数据概览、快捷操作、最近记录
3. **采购合同列表**：卡片式列表，状态标签
4. **新建采购合同**：复杂表单，支持动态明细行
5. **AI助手**：右下角悬浮窗，模拟对话交互
6. **AI辅助录入**：模拟文本解析弹窗

## 如何运行
直接在浏览器中打开 `index.html` 即可预览。

```bash
# MacOS
open index.html

# Windows
start index.html
```

## 交互说明
- **登录**：点击登录按钮即可进入系统（模拟延迟）
- **导航**：点击左侧菜单切换页面（目前实现了首页、采购合同、新建采购）
- **AI助手**：点击右下角机器人图标展开对话
- **新建采购**：
  - 点击“AI辅助录入”体验弹窗
  - 动态添加/删除商品行
  - 自动计算金额小计
