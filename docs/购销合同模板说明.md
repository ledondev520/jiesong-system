## 使用方法

1. 进入 **合同管理** 页面
2. 找到需要生成购销合同的 **采购合同**
3. 点击蓝色 **下载图标** 📥
4. 填写：
   - 收货店铺名称
   - 收货地址
   - 收货联系人
   - 首付比例（%）
5. 点击 **生成合同**
6. 下载 Word 文档
7. 如需 PDF，用 Word/WPS 打开后另存为 PDF

## 更换模板

如需使用新的合同模板：
1. 准备新的合同 Word 文档（确保包含上述原文本）
2. 重命名为 `购销合同模板.docx`
3. 上传到 `/backend/templates/` 目录
4. 或通过管理员 API 上传：`POST /api/v1/contract-doc/template`

## 技术说明

- 模板位置：`/backend/templates/购销合同模板.docx`
- 生成方式：AdmZip 解压 DOCX → 文本替换 → 重新打包
- 输出格式：Word (.docx)
