## 二、数据质量分析

### 2.1 数据质量问题汇总

#### ⚠️ 严重问题（影响数据导入）

1. **数值字段包含逗号和空格**
   - 示例：`" 1,545.00 "`, `"144,300 "`, `" 7,596.00 "`
   - 影响字段：采购金额、毛重、净重
   - 处理：去除逗号和空格，转换为数字

2. **字段中包含中文符号和异常字符**
   - 示例：`（件`、`（个`、`（1`、`=3.6*1.2（8)`
   - 影响字段：报关数量、单位、规格
   - 处理：提取有效数字，清理异常字符

3. **多个记录使用相同序号**
   - 示例：序号64有2条记录，序号65有2条记录，序号71有2条记录
   - 原因：同一批货分多行记录
   - 处理：重新生成唯一序号

4. **货柜编号格式不统一**
   - 标准格式：`货柜1`、`货柜2`、`快件1`
   - 新格式：`01-叶总`、`02-振宗`、`13-圣荷西2115`、`27-圣荷西2115`
   - 处理：需要标准化为系统格式（YY-NNN-PORT）

5. **日期字段为空或未来日期**
   - 部分记录出货日期为空
   - 部分记录日期为2025年（未来日期/预计出货）
   - 处理：标记为"预计出货"或"未完成"

#### ⚠️ 中等问题（需要人工确认）

6. **"不相关"标记的记录**
   - 共约30+条记录标记为"不相关"
   - 类型：卡座、火锅底料、超薄石材、餐具等
   - 处理：导入但标记为"不相关"分类

7. **空值字段多**
   - 报关数量、单位、厂家、规格等字段大量为空
   - 处理：允许空值，导入时标记

8. **供应商名称不统一**
   - 正式名称：`佛山XX陶瓷有限公司`
   - 昵称：`黎总`、`叶总`、`郭总`、`淘宝`、`阿宗`
   - 处理：建立昵称映射表

9. **报关公司枚举值不完整**
   - 现有值：`捷淞`、`埋单`、`其他厂家报关`、`不报关`
   - 缺失：`合并报关`（文档中提到但CSV中未见）
   - 处理：补充枚举值

#### ℹ️ 低优先级问题

10. **备注信息不规范**
    - 包含业务状态：`生产中`、`运输中`、`包装中`
    - 包含位置信息：`在黎总`、`在何总自助台`、`11月开票`
    - 处理：保留原始备注，系统化提取状态信息

### 2.2 特殊数据模式识别

#### 📌 模式1：一个出口合同关联多个门店

**发现**：同一个出口合同号（EXP）关联了不同门店

**示例**：
```
EXP250013 (货柜11-喜安混合发)
├── 禧瑞都门店（多条记录）
└── 安纳汉姆门店（多条记录）
```

**确认**：您已确认"一个出口合同可包含多个门店"，这是正确的业务逻辑。

**数据库设计影响**：SalesContract 和 Store 的关系需调整。

---

#### 📌 模式2：同一货柜编号对应一个出口合同

**发现**：每个货柜编号只对应一个EXP合同号

**示例**：
- `货柜1` → `EXP2400001` (禧瑞都)
- `货柜2` → `EXP2400002` (禧瑞都)
- `货柜3` → `EXP2400003` (密歇根)

**确认**：您已确认"一个出口合同 = 一个货柜"

---

#### 📌 模式3：供应商昵称使用频繁

**发现**：大量使用昵称而非正式公司名

**常见昵称**：
- `黎总` - 出现最多（瓷砖供应商）
- `叶总` - 火锅器材、餐桌
- `郭总` - 不锈钢门
- `淘宝` - 小件杂货
- `阿宗` - 大理石材
- `刘总` - 卡座
- `何总布菲传奇` - 自助餐台

**处理方案**：建立供应商昵称映射表，导入时自动关联或创建新供应商。

## 三、数据清洗规则

### 3.1 字段清洗规则详细说明

#### 1. 序号 (id)
```javascript
清洗规则：
- 去除重复序号，重新生成唯一序号
- 生成规则：原序号 + 子序号（如：64 → 64-1, 64-2）

示例：
原数据：64, 64, 65, 65
清洗后：64-1, 64-2, 65-1, 65-2
```

```javascript
清洗规则：
- 去除首尾空格
- 保留原始值（必填字段）

- ❌ 空值 → 标记为"异常：报关名缺失"
- ✅ 非空 → 通过
```

- 出货日期为空，或
- 出货日期为未来日期，或

## 四、异常标注方案

### 4.1 异常级别定义

| 级别 | 符号 | 说明 | 处理策略 |
|------|------|------|----------|
| **错误** | 🔴 ERROR | 数据无法导入，必须修复 | 阻止导入，人工修复 |
| **警告** | 🟡 WARNING | 数据可导入，但需人工确认 | 导入+标记，待确认 |
| **信息** | 🔵 INFO | 数据正常，仅提示 | 正常导入，记录日志 |

### 4.2 异常类型及处理

#### 🔴 错误级异常（ERROR）

| 异常代码 | 异常描述 | 触发条件 | 示例 |
|----------|----------|----------|------|
| E001 | 报关名缺失 | customsName为空 | 空值 |
| E002 | 门店缺失 | storeName为空 | 空值 |

### 7.2 CSV文件预处理脚本（可选）

如需批量处理，可使用以下脚本：

```javascript
// scripts/preprocess-csv.js

const fs = require('fs');
const Papa = require('papaparse');

// 读取CSV
const csvData = fs.readFileSync('出货汇总(1).csv', 'utf8');
const parsed = Papa.parse(csvData, { header: true });

// 预处理函数
function preprocessRow(row) {
  // 1. 清理采购金额
  if (row['采购金额']) {
    row['采购金额'] = row['采购金额']
      .replace(/"/g, '')
      .replace(/,/g, '')
      .trim();
  }
  
  // 2. 标准化报关公司
  const brokerMap = {
    '捷淞': '捷淞',
    '埋单': '埋单',
    '其他厂家报关': '其他厂家报关',
    '不报关': '不报关'
  };
  if (row['报关公司']) {
    row['报关公司'] = brokerMap[row['报关公司']] || row['报关公司'];
  }
  
  // 3. 清理数量字段
  if (row['报关数量']) {
    // 去除异常字符
    row['报关数量'] = row['报关数量']
      .replace(/（/g, '')
      .replace(/）/g, '')
      .replace(/=/g, '')
      .trim();
  }
  
  return row;
}

// 处理所有行
const processed = parsed.data.map(preprocessRow);

// 输出处理后的CSV
const output = Papa.unparse(processed);
fs.writeFileSync('出货汇总_已清洗.csv', output, 'utf8');

console.log('预处理完成！');
```

```sql
SELECT 
  c.containerNo,
  c.totalBoxes AS container_boxes,
  SUM(ci.boxes) AS sum_boxes,
  c.grossWeight AS container_gross,
  SUM(ci.grossWeight) AS sum_gross
```

### Q1: 如果导入失败如何回滚？
**A**: 所有导入操作在一个事务中执行，失败会自动回滚，数据库不会有任何改变。

### Q2: 导入后发现数据错误如何处理？
**A**: 可以使用以下方法：
1. 删除导入批次（通过ImportRecord表的批次ID）
2. 修复CSV数据
3. 重新导入

### Q3: 如何处理重复导入？
**A**: 系统会检测重复的合同号和货柜编号：
- 如果检测到重复，可选择"跳过"或"覆盖"
- 建议首次导入用"跳过"，更新数据用"覆盖"

### Q4: CSV文件编码问题怎么办？
**A**: 
- 优先使用UTF-8编码
- 系统会自动检测编码
- 如果出现乱码，请将CSV转换为UTF-8后重新上传

### Q5: 导入时间过长怎么办？
**A**: 
- 导入过程显示进度条
- 大批量数据（>500条）会分批处理
- 导入可在后台运行，完成后发送通知

```typescript
// src/services/import.service.ts

import Papa from 'papaparse';

// 数据清洗函数
export function cleanCSVData(rows: any[]): {
  cleaned: any[];
  errors: any[];
  warnings: any[];
} {
  const cleaned = [];
  const errors = [];
  const warnings = [];

  rows.forEach((row, index) => {
    const rowNumber = index + 2; // Excel行号（表头占第1行）
    const cleanedRow: any = {};
    const rowErrors = [];
    const rowWarnings = [];

    // 1. 清洗报关名
    if (!row['报关名'] || row['报关名'].trim() === '') {
      rowErrors.push({
        code: 'E001',
        field: 'customsName',
        message: '报关名缺失'
      });
    } else {
      cleanedRow.customsName = row['报关名'].trim();
    }

    // 2. 清洗门店
    if (!row['门店'] || row['门店'].trim() === '') {
      rowErrors.push({
        code: 'E002',
        field: 'storeName',
        message: '门店缺失'
      });
    } else {
      cleanedRow.storeName = standardizeStoreName(row['门店'].trim());
    }

    // 3. 清洗港口
    const port = cleanPortName(row['港口']?.trim());
    if (!port) {
      rowErrors.push({
        code: 'E003',
        field: 'portName',
        message: '港口缺失或无效'
      });
    } else {
      cleanedRow.portName = port.name;
      cleanedRow.portCode = port.code;
    }

    // 4. 清洗数量
    const quantity = parseQuantity(row['报关数量']);
    if (quantity === null && row['报关数量']) {
      rowWarnings.push({
        code: 'W001',
        field: 'quantity',
        message: '数量格式异常，需人工确认',
        value: row['报关数量']
      });
    }
    cleanedRow.quantity = quantity;

    // 5. 清洗采购金额
    const amount = parseAmount(row['采购金额']);
    cleanedRow.purchaseAmount = amount;
    if (!amount && row['采购金额']) {
      rowWarnings.push({
        code: 'W009',
        field: 'purchaseAmount',
        message: '采购金额格式异常',
        value: row['采购金额']
      });
    }

    // 6. 清洗货柜编号
    const containerNo = standardizeContainerNo(
      row['柜子编号'],
      row['出货日期'],
      port?.code
    );
    if (!containerNo) {
      rowErrors.push({
        code: 'E005',
        field: 'containerNo',
        message: '柜号缺失或格式错误'
      });
    } else {
      cleanedRow.containerNo = containerNo;
    }

    // 7. 清洗合同号
    if (!row['合同号'] || row['合同号'].trim() === '') {
      rowErrors.push({
        code: 'E004',
        field: 'salesContractNo',
        message: '合同号缺失'
      });
    } else {
      cleanedRow.salesContractNo = row['合同号'].trim();
    }

    // 8. 其他字段...
    cleanedRow.description = row['商品补充信息']?.trim() || null;
    cleanedRow.unit = standardizeUnit(row['单位']?.trim());
    cleanedRow.supplierName = row['厂家']?.trim() || null;
    cleanedRow.specification = row['规格']?.trim() || null;
    cleanedRow.boxes = parseInt(row['箱数']) || null;
    cleanedRow.grossWeight = parseFloat(row['毛重']?.replace(/,/g, '')) || null;
    cleanedRow.netWeight = parseFloat(row['净重']?.replace(/,/g, '')) || null;
    cleanedRow.volume = parseFloat(row['体积']?.replace(/\s/g, '')) || null;
    cleanedRow.shippedAt = parseDate(row['出货日期']);
    cleanedRow.customsBroker = row['报关公司']?.trim() || null;
    cleanedRow.isPaid = row['是否付款'] === '1' || row['是否付款'] === '是';
    cleanedRow.purchaseContractNo = row['购销合同号']?.trim() || null;
    cleanedRow.invoiceNo = row['发票号码']?.trim() || null;
    cleanedRow.note = row['备注']?.trim() || null;
    cleanedRow.isFumigated = row['是否熏蒸'] === '是';
    cleanedRow.hasTaxRefund = row['是否报出口退税'] === '是';

    // 检查"不相关"标记
    if (cleanedRow.note?.includes('不相关')) {
      rowWarnings.push({
        code: 'I001',
        field: 'note',
        message: '不相关记录',
        value: cleanedRow.note
      });
      cleanedRow.tags = ['不相关'];
    }

    // 检查预计出货
    if (!cleanedRow.shippedAt || new Date(cleanedRow.shippedAt) > new Date()) {
      rowWarnings.push({
        code: 'W008',
        field: 'shippedAt',
        message: '预计出货',
        value: row['出货日期']
      });
      cleanedRow.tags = [...(cleanedRow.tags || []), '预计出货'];
    }

    // 汇总结果
    if (rowErrors.length > 0) {
      errors.push({
        rowNumber,
        errors: rowErrors,
        rawData: row
      });
    } else {
      cleaned.push(cleanedRow);
      if (rowWarnings.length > 0) {
        warnings.push({
          rowNumber,
          warnings: rowWarnings,
          data: cleanedRow
        });
      }
    }
  });

  return { cleaned, errors, warnings };
}

// 辅助函数
function parseQuantity(value: string): number | null {
  if (!value) return null;
  
  // 去除异常字符
  const cleaned = value
    .replace(/（/g, '')
    .replace(/）/g, '')
    .replace(/=/g, '')
    .trim();
  
  const num = parseFloat(cleaned);
  return isNaN(num) ? null : num;
}

function parseAmount(value: string): number | null {
  if (!value) return null;
  
  const cleaned = value
    .replace(/"/g, '')
    .replace(/,/g, '')
    .trim();
  
  const num = parseFloat(cleaned);
  return isNaN(num) ? null : num;
}

function cleanPortName(name: string): { name: string; code: string } | null {
  const portMap: Record<string, { name: string; code: string }> = {
    '洛杉矶': { name: '洛杉矶', code: 'LA' },
    'Oakland': { name: 'Oakland', code: 'OAK' },
    '密歇根': { name: '密歇根', code: 'MI' }
  };
  
  return portMap[name] || null;
}

function standardizeStoreName(name: string): string {
  // 标准化门店名称
  const storeMap: Record<string, string> = {
    'Burbank店': 'Burbank',
    '安纳汉姆': 'Burbank', // 如果是同一门店
    // ... 其他映射
  };
  
  return storeMap[name] || name;
}

function standardizeUnit(unit: string): string | null {
  if (!unit) return null;
  
  // 去除异常字符
  const cleaned = unit
    .replace(/（/g, '')
    .replace(/）/g, '')
    .trim();
  
  return cleaned || null;
}

function standardizeContainerNo(
  no: string,
  date: string,
  portCode: string
): string | null {
  if (!no) return null;
  
  // 已经是标准格式
  if (/^\d{2}-\d{3}-[A-Z]+$/.test(no)) {
    return no;
  }
  
  // 提取年份
  const year = date ? new Date(date).getFullYear().toString().slice(-2) : '25';
  
  // 提取序号
  const match = no.match(/(\d+)/);
  const seq = match ? match[1].padStart(3, '0') : '001';
  
  // 组合
  return `${year}-${seq}-${portCode}`;
}

function parseDate(dateStr: string): string | null {
  if (!dateStr) return null;
  
  try {
    const date = new Date(dateStr);
    return date.toISOString().split('T')[0]; // YYYY-MM-DD
  } catch {
    return null;
  }
}
```
