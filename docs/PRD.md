## 一、产品概述

### 1.1 产品定位

面向外贸出口企业的**一站式进销存管理系统**，集成AI智能助手，实现采购、销售、库存、财务的数字化管理。

### 1.2 目标用户

| 角色 | 描述 |
|------|------|
| 管理员/老板 | 企业负责人，需要全局掌控业务数据，进行决策分析 |
| 采购人员 | 负责与供应商沟通、签订合同、跟踪付款和到货 |
| 销售人员 | 负责与门店客户沟通、报价、签订出口合同、收款 |

### 1.3 核心价值

| 价值点 | 说明 |
|--------|------|
| **数据集中** | 采购、销售、库存、财务数据统一管理，告别Excel |
| **AI赋能** | 智能问答快速获取信息，辅助录入提升效率 |
| **流程规范** | 合同编号自动生成，业务流程标准化 |
| **追溯查询** | 商品位置、货柜内容、历史记录一键查询 |
| **财务清晰** | 应收应付账款一目了然，付款状态实时跟踪 |

## 二、业务流程

### 2.1 采购流程

```
┌─────────────┐    ┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│  与供应商沟通 │ → │  签订采购合同 │ → │   支付定金   │ → │   生产中    │
│  询价/报价   │    │  CG编号生成  │    │  记录付款   │    │  状态跟踪   │
└─────────────┘    └─────────────┘    └─────────────┘    └─────────────┘
                                                               ↓
┌─────────────┐    ┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│   完成结算   │ ← │  装柜发运    │ ← │   入库      │ ← │ 到达装货点   │
│  支付尾款   │    │  【出库】    │    │  【入库】   │    │  运输中     │
└─────────────┘    └─────────────┘    └─────────────┘    └─────────────┘
```

### 2.2 销售流程

```
┌─────────────┐    ┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│  门店询价   │ → │  智能定价    │ → │  签订出口合同│ → │   收款     │
│             │    │  推荐售价   │    │  EXP编号生成 │    │  先款后货  │
└─────────────┘    └─────────────┘    └─────────────┘    └─────────────┘
                                                               ↓
                                       ┌─────────────┐    ┌─────────────┐
                                       │  确认收货   │ ← │   发货     │
                                       │  应收结清   │    │  货柜发运  │
                                       └─────────────┘    └─────────────┘
```

### 2.3 库存流程（模式B）

```
┌─────────────────────────────────────────────────────────────────────┐
│                           库存管理                                  │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│   采购入库                          销售出库                        │
│   ┌───────┐                        ┌───────┐                       │
│   │ 商品A │ ──入库──→ 【库存池】 ──出库──→ │ 出口合同1 │            │
│   │ 商品B │           (装货点)            │ 出口合同2 │            │
│   │ 商品C │                               │ ...      │            │
│   └───────┘                               └───────┘                │
│                                                                     │
│   特点：商品先入库，出库时关联出口合同                               │
└─────────────────────────────────────────────────────────────────────┘
```

### 2.4 货柜装箱流程

```
┌─────────────┐    ┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│  创建货柜   │ → │  选择商品    │ → │  录入装箱信息│ → │   发运     │
│  自动编号   │    │  关联出口合同│    │  毛重/净重等 │    │  更新状态  │
│ 25-001-LA  │    │  同港优先   │    │             │    │  预计到达  │
└─────────────┘    └─────────────┘    └─────────────┘    └─────────────┘
```

## 四、用户故事

### 4.1 采购场景

#### US-001: AI辅助录入采购信息
```
作为 采购人员
我想要 粘贴供应商发来的报价单文字，由AI自动解析
以便于 快速录入采购信息，减少手工输入错误

验收标准：
1. 支持粘贴文本格式的报价信息
2. AI能识别：商品名称、数量、单价、供应商、规格等字段
3. 解析结果可预览和修改
4. 确认后自动创建采购记录
5. 解析失败时提示用户补充信息
```

#### US-002: 采购合同管理
```
作为 采购人员
我想要 创建采购合同并上传合同文件
以便于 规范管理采购流程，留存合同档案

验收标准：
1. 合同编号CG自动生成（格式：CG25XXXXX）
2. 支持上传PDF/图片格式的合同文件
3. 可关联供应商、商品、金额等信息
4. AI可从合同文件提取供应商公司名称
```

#### US-003: 付款管理
```
作为 采购人员/管理员
我想要 记录每笔付款（定金/尾款）
以便于 清楚了解付款进度和欠款情况

验收标准：
1. 支持多次付款记录（定金、尾款）
2. 每笔付款记录金额、时间、方式
3. 自动计算未付金额
4. 显示付款状态（未付/部分付/已付清）
```

### 4.2 销售场景

#### US-004: 智能定价
```
作为 销售人员
我想要 系统自动计算推荐售价
以便于 快速报价，确保利润率

验收标准：
1. 输入采购成本后自动计算推荐售价
2. 公式：采购价 ÷ (汇率-0.2) × 1.3
3. 支持向上/向下取整
4. 支持手动调整最终售价
5. 汇率和利润率可在系统配置中修改
```

#### US-005: 出口合同管理
```
作为 销售人员
我想要 创建出口合同并关联门店
以便于 规范管理销售流程

验收标准：
1. 合同编号EXP自动生成（格式：EXP25XXXXX）
2. 关联门店、商品、数量、售价
3. 自动计算合同总金额
```

### 4.3 库存场景

#### US-006: 库存入出库
```
作为 采购人员
我想要 记录商品入库和出库
以便于 跟踪商品流转状态

验收标准：
1. 入库：选择商品、数量，记录到达装货点
2. 出库：选择商品、数量、关联出口合同、货柜
3. 库存状态自动更新
4. 支持查询当前库存数量
```

### 4.4 货柜场景

#### US-007: 货柜管理
```
作为 采购人员
我想要 创建货柜并管理装箱
以便于 规范货柜装运流程

验收标准：
1. 货柜编号自动生成（格式：25-001-LA）
2. 添加商品到货柜，录入箱数、毛重、净重、体积
3. 一个货柜可装多个门店的货物
4. 支持录入预计到达时间
5. 发运后更新状态
```

#### US-008: 商品位置查询
```
作为 任意用户
我想要 快速查询商品在哪个货柜
以便于 回答客户关于商品位置的询问

验收标准：
1. 输入商品名称可查询其所在货柜
2. 显示货柜编号、发运状态、预计到达时间
3. 同时显示同货柜的其他商品列表
```

### 4.5 AI助手场景

#### US-009: 智能问答
```
作为 任意用户
我想要 通过对话方式查询业务数据
以便于 快速获取信息，无需记忆复杂的查询路径

验收标准：
1. 支持自然语言提问
2. 可查询：库存、销售、采购、货柜等业务数据
3. 可回答通用问题（如汇率查询）
4. 保持对话上下文
5. 对话历史可保存和查看
```

#### US-010: AI辅助录入货柜到达时间
```
作为 采购人员
我想要 通过对话方式更新货柜到达时间
以便于 简化操作流程

验收标准：
1. 输入如"25-001-LA货柜预计1月15号到达"
2. AI解析货柜编号和日期
3. 展示解析结果供确认
4. 确认后自动更新货柜信息
```
