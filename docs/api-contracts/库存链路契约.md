# 库存链路契约

> 版本：v1.0（2026-02-12）
> 适用范围：库存状态页、库存管理页、批量状态流转

## 1. 目的/边界/职责
- 目的：统一库存链路查询、状态流转与批量更新的接口契约。
- 边界：仅定义 API 请求/响应与错误语义，不包含实现细节。
- 职责：为前后端联调、测试验收提供单一事实来源。

## 2. 接口清单

| 接口 | 方法 | 说明 |
|---|---|---|
| `/api/v1/inventory` | `GET` | 获取库存分页列表（支持关键词查询） |
| `/api/v1/inventory/:id/status` | `PUT` | 更新单条库存状态（状态机约束） |
| `/api/v1/inventory/batch-status` | `PUT` | 批量更新库存状态（逐条校验） |
| `/api/v1/inventory/stats` | `GET` | 获取库存统计 |

## 3. 详细契约

### 3.1 获取库存列表

- **Method**: `GET /api/v1/inventory`
- **Query 参数**:
  - `page?: number` 默认 `1`
  - `pageSize?: number` 默认 `20`
  - `status?: string` 库存状态
  - `productId?: string` 商品ID
  - `keyword?: string` 关键词（匹配商品名或采购合同号）

**请求示例**

```http
GET /api/v1/inventory?page=1&pageSize=100&keyword=CG2500
```

**响应示例**

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "items": [
      {
        "id": "inv_001",
        "status": "INBOUND",
        "quantity": 120,
        "product": { "customsName": "瓷砖A" },
        "purchaseItem": {
          "purchaseContract": { "contractNo": "CG2500001" }
        }
      }
    ],
    "pagination": {
      "page": 1,
      "pageSize": 100,
      "total": 1,
      "totalPages": 1
    }
  }
}
```

### 3.2 更新单条库存状态

- **Method**: `PUT /api/v1/inventory/:id/status`
- **Body**:
  - `status: "PRODUCING" | "PACKING" | "SHIPPING" | "INBOUND" | "OUTBOUND"`

**状态机规则**

- `PRODUCING -> PACKING`
- `PACKING -> SHIPPING`
- `SHIPPING -> INBOUND`
- `INBOUND -> OUTBOUND`（必须存在 `salesContractId`）
- `OUTBOUND` 为终态，不允许继续流转

**失败响应示例（非法流转）**

```json
{
  "code": 400,
  "message": "非法状态流转: PRODUCING -> OUTBOUND",
  "data": null
}
```

### 3.3 批量更新库存状态

- **Method**: `PUT /api/v1/inventory/batch-status`
- **Body**:
  - `ids: string[]` 非空数组
  - `status: InventoryStatus`

**请求示例**

```json
{
  "ids": ["inv_001", "inv_002"],
  "status": "OUTBOUND"
}
```

**响应示例**

```json
{
  "code": 200,
  "message": "批量状态更新完成",
  "data": {
    "success": 1,
    "failed": 1,
    "errors": [
      { "id": "inv_002", "message": "入库记录未绑定出口合同，禁止出库" }
    ]
  }
}
```

## 4. 兼容策略

- `GET /inventory` 新增 `keyword` 为可选参数，对旧调用完全兼容。
- 单条更新接口路径不变，仅在非法状态流转时返回明确业务错误。
- 批量更新为新增接口，不影响旧功能。
