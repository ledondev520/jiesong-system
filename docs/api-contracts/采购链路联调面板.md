# 采购链路联调面板（V1）

## 目的/边界/职责
- 目的：用统一状态追踪采购链路前后端联调进展。
- 边界：仅覆盖采购链路，不含销售/库存等其他域。
- 职责：明确 READY/BLOCKED/DONE 与责任人，快速解除阻塞。

## 状态定义
- `READY`：契约清晰，具备开始联调条件。
- `BLOCKED`：存在阻塞，需指定 owner 解除。
- `DONE`：已联调验证通过并有证据。
