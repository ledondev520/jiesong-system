# 采购链路 API 契约（V1）

## 目的/边界/职责
- 目的：明确采购链路接口的请求/响应、参数约束与错误行为。
- 边界：覆盖 `/api/v1/purchases` 及其子资源，不包含销售/库存链路。
- 职责：为前后端联调、测试与回归提供统一契约基线。

## 通用约定
- Base URL：`/api/v1`
- 鉴权：除登录外接口均要求 `Authorization: Bearer <token>`
- 成功响应结构：
```json
{
  "code": 200,
  "message": "获取成功",
  "data": {}
}
```
- 分页响应结构（列表）：
```json
{
  "code": 200,
  "message": "获取成功",
  "data": {
    "items": [],
    "pagination": {
      "total": 0,
      "page": 1,
      "pageSize": 20,
      "totalPages": 0
    }
  }
}
```
- 错误响应结构：
```json
{
  "code": 400,
  "message": "错误信息",
  "data": null
}
```

## 接口清单

### 1) 获取采购合同列表
- Method/Path：`GET /api/v1/purchases`
- Query：
  - `page` number，默认 `1`
  - `pageSize` number，默认 `20`
  - `status` string，可选
  - `supplierId` string，可选
  - `keyword` string，可选（匹配 `contractNo` / `supplier.name`）
- 200：返回分页列表（含 `supplier`、`items`、`_count`）

### 2) 获取采购合同详情
- Method/Path：`GET /api/v1/purchases/:id`
- Path：
  - `id` string，必填
- 200：返回合同详情（含 `supplier`、`items.product`、`payments`、`files`）
- 404：`采购合同不存在`

### 3) 创建采购合同
- Method/Path：`POST /api/v1/purchases`
- Body：
  - `supplierId` string，必填
  - `taxRate` number，可选，默认 `13`
  - `signedAt` string(datetime)，可选
  - `expectedDate` string(datetime)，可选
  - `note` string，可选
- 201：创建成功，后端自动生成 `contractNo`（`CG` + 年份2位 + 5位序号）
- 400：`供应商ID不能为空`

### 4) 更新采购合同
- Method/Path：`PUT /api/v1/purchases/:id`
- Path：
  - `id` string，必填
- Body（可选字段）：
  - `taxRate` number
  - `signedAt` string(datetime)
  - `expectedDate` string(datetime)
  - `invoiceNo` string
  - `note` string
- 200：更新后的合同

### 5) 删除采购合同
- Method/Path：`DELETE /api/v1/purchases/:id`
- Path：
  - `id` string，必填
- 200：删除成功

### 6) 添加采购明细
- Method/Path：`POST /api/v1/purchases/:id/items`
- Path：
  - `id` string，合同ID
- Body：
  - `productId` string，必填
  - `quantity` number，必填
  - `unit` string，可选
  - `unitPrice` number，必填
  - `specification` string，可选
  - `note` string，可选
- 201：返回新增明细；后端同步回写合同 `totalAmount`

### 7) 更新合同状态
- Method/Path：`PUT /api/v1/purchases/:id/status`
- Path：
  - `id` string，必填
- Body：
  - `status` string，必填
- 200：返回更新后的合同

### 8) 上传合同文件
- Method/Path：`POST /api/v1/purchases/:id/files`
- Path：
  - `id` string，必填
- FormData：
  - `file` 文件，必填
- 201：返回文件记录（`fileName/filePath/fileType/fileSize`）
- 400：`请选择要上传的文件`

### 9) 获取合同文件列表
- Method/Path：`GET /api/v1/purchases/:id/files`
- Path：
  - `id` string，必填
- 200：返回文件数组（按 `uploadedAt` 倒序）

### 10) 删除合同文件
- Method/Path：`DELETE /api/v1/purchases/files/:fileId`
- Path：
  - `fileId` string，必填
- 200：删除成功
- 404：`文件不存在`

### 11) 获取下一个合同编号
- Method/Path：`GET /api/v1/purchases/options/next-no`
- 200：
```json
{
  "code": 200,
  "message": "操作成功",
  "data": {
    "contractNo": "CG2500001"
  }
}
```

### 12) 根据商品获取历史供应商
- Method/Path：`POST /api/v1/purchases/suppliers-by-products`
- Body：
  - `productIds` string[]，必填（允许空数组）
- 200：
```json
{
  "code": 200,
  "message": "操作成功",
  "data": {
    "supplierIds": ["supplier-1", "supplier-2"]
  }
}
```
