# 销售链路联调面板（V1）

## 目的/边界/职责
- 目的：追踪销售链路前后端联调状态与阻塞解除动作。
- 边界：覆盖销售合同、装箱、状态流转与辅助接口。
- 职责：提供 READY/BLOCKED/DONE 可视化台账，降低联调扯皮成本。

## 状态定义
- `READY`：契约明确，可开始联调。
- `BLOCKED`：存在阻塞，需 owner 处理。
- `DONE`：联调通过并有证据链。
