## 一、核心业务流程（用户真实需求）

根据用户描述，系统的核心使用场景是：

```
采购人员/销售人员 → 录入采购订单 → 商品入库 → 分配到门店 → 装柜 → 输出合同/单据
```

### 1.1 简化后的核心功能

| 功能 | 说明 | 用户操作 |
|------|------|----------|
| **采购录入** | 录入采买的商品信息 | 选择供应商、商品、数量、价格 |
| **商品目录** | 管理所有商品的基本信息 | 商品名、规格、体积、重量等 |
| **门店分配** | 记录哪些货物给哪个门店 | 关联商品与门店 |
| **装柜管理** | 定义哪些货物放哪个柜子 | 选择商品装入货柜 |
| **单据输出** | 输出合同/订单文档 | 导出 Excel（三个 Sheet） |

## 七、已完成的功能（2026-01-20）

### 7.1 数据模型重构 ✅
**合并货柜与出口合同，一个 EXP 号 = 一个货柜**

变更内容：
- 移除 Container 表，功能合并到 SalesContract
- ContainerItem 改名为 PackingItem，关联 SalesContract
- SalesContract 新增字段：portId, totalBoxes, grossWeight, netWeight, volume, shippedAt, estimatedArrival 等
- 简化操作流程，减少实体数量

### 7.2 商品模型扩展 ✅
新增字段用于 3D 可视化：
- `length` - 长度 (mm)
- `width` - 宽度 (mm)
- `height` - 高度 (mm)
- `grossWeight` - 毛重 (kg/箱)
- `netWeight` - 净重 (kg/箱)
- `volume` - 体积 (CBM/箱)
- `packingSpec` - 包装规格

### 7.3 3D 货柜可视化 ✅
- 路径：`/dashboard/sales/[id]` → 3D 可视化 Tab
- 技术栈：Three.js + react-three-fiber
- 功能：
  - 40HQ 标准货柜 3D 模型（12030×2350×2690 mm）
  - 根据商品尺寸自动装箱排列
  - 不同商品用不同颜色区分
  - 显示装箱统计（已装/未装/利用率）
  - 支持旋转、缩放、平移查看

### 7.4 出口合同详情页 ✅
- 路径：`/dashboard/sales/[id]`
- 三个标签页：
  1. **装箱明细** - 管理货柜内商品
  2. **3D 可视化** - 查看装箱效果
  3. **合同信息** - 查看合同基本信息
- 容量概览卡片（箱数、体积、重量、金额）

### 7.5 购销合同自动生成 ✅
- 供应商模型扩展：phone, taxId, bankName
- 后端 API：`POST /api/v1/contract-doc/generate/:id`
- 前端：合同管理页面添加"生成购销合同"按钮
- 模板文件位置：`/backend/templates/购销合同模板.docx`
- 使用说明：`/docs/购销合同模板说明.md`
