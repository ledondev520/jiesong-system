# 销售角色异常生命周期回归（2026-10-05）

基线：`40efbaa`。使用本机回环 HTTP 和权限为 0700/0600 的临时合成 SQLite；所有鉴权由实际中间件与数据库用户执行，没有 API 鉴权 mock。未访问生产数据、用户电脑、公开浏览器、外部付款或邮件服务。

## 本轮新增矩阵

| 场景 | 修复前/本轮发现 | 修复后证据 |
| --- | --- | --- |
| 无令牌/停用 SALES 创建 | 实际 401，业务表不变 | 新 HTTP 回归通过 |
| BOSS 创建、SALES 新建管理员账号 | 实际 403；JWT 中伪造 ADMIN 声明不能提升数据库角色 | 新 HTTP 回归通过 |
| SALES 收货/验货、受限财务证据、退税确认准备 | 实际 403，收货/验货表不变 | 新 HTTP 回归通过 |
| DRAFT 直接发运/到港/完成/未知状态 | 销售主入口实际 400 | 销售及旧货柜状态入口均 400，业务表不变 |
| 旧货柜状态入口直接发运 | 实际返回 200；无需装箱/库存即可变为 SHIPPED | 委托同一销售状态机、装载与原子出库事务 |
| 旧货柜表头携 status 与 note 跳状态 | 实际返回 200，两字段都被修改 | 400，note 等其他表头字段也不写入；携带未变状态的资料更新仍可成功 |
| 旧货柜新建携 SHIPPED | 实际返回 201，制造空的已发运单 | 非 DRAFT 一律 400；普通 DRAFT 新建保持可用 |
| CANCELLED 重试、同创建键重放/不同内容 | 主入口取消重试和创建重放通过；旧入口可复活取消单 | 两入口均不能恢复取消单；创建重放返回原取消单，不重复新建；不同内容为 409 |
| 两商品出库，第一商品够、第二商品不足 | 销售主入口回滚；旧状态入口返回 200 绕过扣库 | 两入口均 400，第一商品扣库、合同状态、发运时间全量回滚 |
| 两合同各需 60 件，共用 100 件库存 | 新验证 | 第一单旧入口实际扣 60 留 40；第二单两入口均拒绝，仍 PACKING 且发运时间为空 |
| 两入口重复 SHIPPED | 新跨入口验证 | 库存不重复扣减，发运时间不变 |
| SHIPPED 回退 DRAFT/CANCELLED 或直接 COMPLETED | 新跨入口验证 | 全部 400；表头绕过同样拒绝 |
| 到港但未收齐款手工完成 | 新跨入口验证 | 两入口均 400；实际合成内部收款登记后自动 COMPLETED，库存不变 |
