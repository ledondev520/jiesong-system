# 🚀 采购与供应链管理系统 (ERP) 开发需求全案 (V2.0)

**提案人：** 采购部
**日期：** 2026-03-18
**核心目标：** 消除机械化手工录入，实现 [合同自动生成]、[单价智能比对] 与 [数据实时同步]。

---

## 一、 系统核心逻辑架构
系统需打通从 1688 选品到最终出货登记的全链路数据：
**[供应商/产品库] ➔ [单价自动比价] ➔ [合同自动生成] ➔ [云端自动归档] ➔ [出货清单同步]**

---

## 二、 功能模块详细需求表

| 业务模块 | 输入项 (Manual Input) | 系统自动化逻辑 (Auto-Logic) | 同步/输出结果 (Output) |
| :--- | :--- | :--- | :--- |
| **供应商档案** | 店名、开票全称、税号、样张截图 | 1. 建立唯一供应商 ID；<br>2. 自动标注“佛山/珠三角”地理标签。 | **资质预警**：无专票资质或异地发货时自动提示。 |
| **单价智能比对** | 输入产品 SKU & 单价 | 1. **自动检索**：调取该供应商及全库历史成交价；<br>2. **涨跌分析**：计算与上次成交单价的偏差率。 | **实时反馈**：<br>🟢 低于历史价：显示“价格优异”；<br>🔴 高于上次价：显示“涨价预警”。 |
| **合同自动化** | 选择供应商 + 数量 | 1. **自动编号**：`CG` + `YY` (26) + `5位流水号` (如 CG2600014)；<br>2. **自动填充**：调取开票信息、计算含税含运费总价。 | **一键生成**：导出符合公司模板的 Word/PDF 合同。 |
| **云端归档** | 合同确认生成 | 通过 API 接口自动上传至 **[金山云文档]** 指定文件夹。 | **数字资产**：无需手动保存，实现合同云端化管理。 |
| **出货清单同步** | (由合同生成触发) | 自动在《出货清单》新增一行，带入合同号、店名、单价、总额、港口。 | **零录入同步**：消除手动誊抄，确保 Excel 数据准确。 |
| **物流数据补录** | 净重、毛重、体积、发票号 | 1. 对应合同行进行数据填报；<br>2. 自动计算订单总体积 (CBM)。 | **状态变更**：台账自动更新为“已发出/已收票”。 |

## 三、 深度细节需求 (针对开发者 Stans Xu)

### 1. 合规性“智能助手” (Compliance)
* **逻辑**：输入特定品名（如：鸟刺）时，系统自动弹窗显示美国对应州（如：洛杉矶）的尺寸限制标准。
* **价值**：确保采购品 100% 符合餐厅当地法律，规避退货风险。

### 2. 价格波动“红绿灯” (Price Guard)
* **逻辑**：若单价高于上次成交价，系统强制要求录入“涨价备注”，并在老板审核界面高亮显示。
* **价值**：辅助老板把控采购成本，防止供应商非理性涨价。

### 3. 供应商协作入口 (Vendor Portal)
* **逻辑**：生成临时链接/小程序，由商家自行上传：
  * 包装数据（毛净重/体积）；
  * 生产确认视频及照片。
* **价值**：将录入压力前置给供应商，采购员仅需在线审核。

### 4. 附件“全家桶”管理
* **逻辑**：在《出货清单》每一行均可点击查看关联附件：
  * **报价单 Excel**、**盖章合同 PDF**、**厂家专票截图**、**生产视频**。

## 四、 数据库关键字段定义 (Field Definition)
1. `Contract_ID`: 合同号 (CG+YY+XXXXX)
2. `Historical_Min_Price`: 历史最低成交价
3. `Last_Purchase_Price`: 上次成交单价
4. `Port_Location`: 发货港口 (珠三角关联)
5. `Packaging_Data`: GW/NW/CBM (毛净重/体积)
6. `Invoice_Status`: 发票状态及号码
7. `Cloud_Link`: 金山云文件路径
