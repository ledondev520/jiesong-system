# 进销存系统 - 测试替身与示例数据清单

> - Input: 业务源码与文档中的历史占位标记
> - Output: 当前运行态清理结论与保留范围
> - Pos: 技术债追踪（运行态与测试态边界）

---

## 一、运行态清理结论

- 前端业务页/服务层已移除历史占位注释与示例返回路径。
- 后端控制器与服务层已使用真实业务逻辑，不再保留占位数据分支。
- 货柜域统一使用 `contractNo` 作为编号字段，不再提供兼容别名字段。

---

## 二、允许保留范围（仅测试态）

- 单元测试、集成测试与 E2E 场景可继续使用测试替身（如 `vi.fn`、路由拦截、响应桩），用于稳定自动化验证。
- 测试态替身不得进入 `frontend/src/app` 与 `backend/src/controllers|services` 的运行路径。

---

## 三、巡检规则

- 运行态检查：`rg -n "(占位|示例返回|测试替身)" frontend/src backend/src --glob '!**/*.test.*' --glob '!frontend/e2e/**'`
- 文档检查：禁止在对外接口说明中使用占位返回作为生产行为描述。
