## 一、技术选型

### 1.1 技术栈总览

| 层级 | 技术选型 | 说明 |
|------|----------|------|
| **前端框架** | Next.js 14 (App Router) | React全栈框架，SSR/SSG支持 |
| **UI组件** | Tailwind CSS + shadcn/ui | 原子化CSS + 高质量组件库 |
| **状态管理** | Zustand | 轻量级状态管理 |
| **表单处理** | React Hook Form + Zod | 表单验证 |
| **后端** | Next.js API Routes | 无需单独后端服务 |
| **ORM** | Prisma | 类型安全的数据库访问 |
| **数据库** | SQLite | 轻量级，单文件，易部署 |
| **认证** | NextAuth.js | 开箱即用的认证方案 |
| **AI** | Kimi API | 智能问答和辅助录入 |
| **文件存储** | 本地文件系统 | 合同文件等 |

### 1.2 选型理由

#### Next.js 14
- 全栈框架，前后端统一技术栈（JS）
- App Router提供更好的布局和路由管理
- API Routes替代独立后端
- 内置优化（代码分割、图片优化等）
- 响应式设计友好

#### SQLite + Prisma
- SQLite无需安装数据库服务，部署简单
- 单文件数据库，备份方便
- Prisma提供类型安全的ORM，开发体验好
- 支持迁移管理

#### shadcn/ui
- 基于Radix UI，可访问性好
- 代码可定制，不是黑盒组件库
- 与Tailwind CSS完美配合
- 组件质量高，设计美观

## 六、AI集成方案

### 6.1 Kimi API配置

```typescript
// src/lib/kimi.ts
import OpenAI from 'openai';

const kimiClient = new OpenAI({
  apiKey: process.env.KIMI_API_KEY,
  baseURL: 'https://api.moonshot.cn/v1',
});

export async function chatWithKimi(
  messages: Array<{ role: string; content: string }>,
  options?: { temperature?: number }
) {
  const response = await kimiClient.chat.completions.create({
    model: 'moonshot-v1-8k',
    messages,
    temperature: options?.temperature ?? 0.3,
  });
  
  return response.choices[0].message.content;
}
```

- 销售合同和应收款
- 货柜信息和商品位置

当用户询问业务数据时，你需要：
1. 理解用户意图
2. 生成对应的查询参数
3. 返回查询结果的自然语言描述

请以JSON格式返回查询参数，格式如：
{ "action": "query", "entity": "products", "filters": {...} }`;

  // 2. 调用Kimi获取查询参数
  const aiResponse = await chatWithKimi([
    { role: 'system', content: systemPrompt },
    { role: 'user', content: query }
  ]);
  
  // 3. 解析AI返回的查询参数
  const queryParams = parseAIResponse(aiResponse);
  
  // 4. 执行数据库查询
  const data = await executeQuery(queryParams);
  
  // 5. 将数据交给AI生成自然语言回复
  return formatResponse(data, query);
}

    return config.value;
  }
