## 二、业务背景

### 业务模式
- B2B外贸出口业务
- 从国内供应商采购 → 向美国门店销售
- 涉及报关、熏蒸、出口退税等流程

### 核心流程
```
采购流程：与供应商沟通 → 签订合同(CG) → 支付定金 → 生产 → 到达装货点(入库) → 装柜发运(出库)

销售流程：门店下单 → 签订出口合同(EXP) → 收款 → 发货 → 应收账款跟踪

库存模式：模式B - 商品先入库，出库时关联出口合同
```

### 定价公式
```
售价（美元）= 采购成本（人民币）÷ (汇率 - 0.2缓冲) × 利润率(默认1.3)

示例：7000元 ÷ 6.8 × 1.3 ≈ 1338美元，取整后1340或1350美元
```

## 四、功能模块

### 4.1 基础数据管理

#### 商品管理
- 商品档案（报关名、补充信息、规格、单位）
- 商品分类
- 支持同一商品多供应商
- 历史采购价格记录

#### 供应商管理
- 供应商档案
- 正式名称 + 昵称关联（如"黎总" → "佛山XX陶瓷有限公司"）
- 联系人信息
- **质量问题标记**功能
- 从合同文件AI提取自动建档

#### 客户门店管理
- 门店档案
- 绑定港口
- 联系人

#### 港口管理
- 港口列表：洛杉矶(LA)、Oakland(OAK)、密歇根(MI)

---

### 4.2 采购管理

#### 采购合同
- CG编号自动生成（格式：CG25XXXXX）
- 合同文件上传（PDF/图片）
- AI提取合同信息

#### AI辅助录入
```
采购员粘贴供应商报价
       ↓
AI解析（商品、数量、单价、供应商、门店等）
       ↓
展示解析结果，采购员确认/修改
       ↓
保存到数据库
       ↓
如解析失败，提示用户补充信息
```

#### 付款管理
- 定金 + 尾款分期记录
- 每笔付款：金额、时间、方式
- 付款状态跟踪

#### 价格提示
- 同商品历史采购价参考
- 不同供应商报价对比

---

### 4.3 销售管理

#### 出口合同
- EXP编号自动生成（格式：EXP25XXXXX）

#### 智能定价
- 自动计算推荐售价
- 支持手动调整
- 向上/向下取整选项

#### 应收账款
- 门店付款跟踪
- 先收款再发货

---

### 4.4 库存管理

#### 状态流转
```
生产中 → 包装中 → 运输中 → 入库(到达装货点) → 出库(装柜发运)
```

> 希望通过Agent机制自动变更状态，具体逻辑后续细化

#### 库存操作
- 入库：货物到达临时装货地点
- 出库：装柜发运，关联出口合同

---

### 4.5 货柜管理

#### 货柜创建
- 编号自动生成：`YY-NNN-PORT`
  - YY: 年份后两位
  - NNN: 三位序号
  - PORT: 港口简码
  - 示例：25-001-LA

#### 装箱管理
- 一柜可装多店
- 优先同港口装一柜
- 装箱明细记录

#### 物流信息
- 箱数、毛重、净重、体积
- **预计到达时间**（物流商提供，AI助手或手动录入）
- 发运状态

#### 货柜查询功能
- **商品位置查询**：快速查询商品在哪个货柜
- **货柜关联查询**：查询A商品时，显示同货柜其他商品
- 直观数据可视化展示

---

### 4.6 报关记录（仅记录）

| 字段 | 类型 |
|------|------|
| 报关公司 | 自由填写 + 枚举建议（捷淞、埋单、其他厂家报关、不报关、合并报关） |
| 是否熏蒸 | 是/否/不适用 |
| 是否报出口退税 | 是/否 |

---

### 4.7 财务管理

#### 应付账款
- 供应商付款跟踪
- 定金 + 尾款

#### 应收账款
- 门店收款跟踪

#### 付款记录
- 每笔付款的金额、时间、方式

---

### 4.8 文件管理

- 采购合同上传（PDF/图片）
- 文件关联到对应采购记录
- AI提取供应商公司名称

---

### 4.9 AI助手功能

#### 智能问答
- 业务数据查询："上个月圣荷西进了多少瓷砖？"
- 通用问题："当前人民币汇率是多少？"
- 数据分析："哪个供应商采购金额最高？"

#### 辅助录入
- 采购信息录入
- 货柜到达时间录入
- 解析 → 确认 → 保存流程

#### 汇率查询
- 定期获取实时汇率
- 自动减0.2作为缓冲

#### 对话管理
- 保存对话历史
- 同一会话保持上下文
- 新开对话独立问答
- 支持审计追溯

## 五、数据来源

### CSV原始字段
```
序号, 报关名, 商品补充信息, 门店, 港口, 报关数量, 单位, 厂家, 规格, 
箱数, 毛重, 净重, 体积, 柜子编号, 出货日期, 合同号, 报关公司, 
是否付款, 购销合同号, 采购金额, 发票号码, 备注, 是否熏蒸, 是否报出口退税
```

- 部分数据格式不统一（需清洗）
