# 出货 Excel 自动生成出口四单

## 使用入口

进入「业务 → 出口订单 → Excel 出四单（管理员）」，上传出货汇总 `.xlsx`。

- 文件只有一票且资料完整：自动下载含「合同、发票、箱单、报关预录信息」的出口四单 Excel。
- 文件含多票：选择本次 EXP，自动生成这一票。
- 需要改价：改本票单价，点「重新计算」，再下载。人工价格优先保留。
- 缺少资料、来源变化或价格约束不满足：在界面显示具体问题，补齐后重试，不猜测、不把缺失值填成0。

此入口是制单，不是合同签署、报关提交、出库或收付款。上传不改变原Excel，也不自动更新业务库的合同、库存和资金记录。

## 已确认的固定规则

1. **沿用原合同、发票、箱单模板，加固定报关预录页。** 前三页保留抬头、字体、边框、条款、银行信息、签章位置和打印范围，只更新本票字段。第四页采用已确认的22列蓝白版式，明细自动扩展并顺延合计。
2. **一行源数据对应一行单据。** 不根据补充信息或备注中的多种设备、附件擅自拆行，不按同名商品自动合并。拆分必须由用户明确提出。
3. **正文保持原格式。** 不加入DRAFT、来源路径、源行号或加价算法。报关预录页保留模板的资料说明及整票提示；同票多个港口时提示按最终订舱资料复核。
4. **保留人工修改。** Excel出口单价、本票手工覆盖价优先于自动报价，不能为了凑30%把人工价改回建议价。
5. **四单同源。** 品名、数量、单位、价格、箱数、毛净重和体积来自同一组选定源行，四张表按相同顺序联动；预录页公式引用本票合同、发票和箱单，不重新定价。

## 固定报关预录信息页

- 包含HS编码、申报要素、成交数量/单位、单价/总价、币制、件重尺、包装规格、货源地、目的国、柜号、出货日期、港口、门店、报关公司和备注。
- Excel的出货日期支持已保存的日期单元格或 `YYYY-MM-DD` 文本；缺失时留空，不用单证日期或1900年填补。多日期、多柜号不强行合成一个表头值，逐行保留。
- Excel的目的国沿用公司合同模板中的明确目的国资料（现有模板 `TO USA`）；数据库入口取订单所关联客户的已登记国家。无依据时留空，外发前核对实际运抵国。
- 数据库入口使用订单当前装箱明细（含仓库/采购来源）、已保存港口、发运日期及柜号；发运时刻按北京时间取日期，Excel日期单元格不加时区偏移。未发运也可生成预录表，出货日期留空。仍沿用既有价格确认、发运后锁价和附件归档流程。
- 历史三单继续被退税资料核验和附件权限识别；以后新生成四单，不重写历史附件。

## 脚本批量制单入口

在已配置模板、税库和运行环境的后端目录运行：

```bash
node scripts/generate-export-packet.js \
  --input '/private/path/出货汇总.xlsx' \
  --output '/private/path/出口四单.xlsx' \
  --options '/private/path/本票参数.json'
```

参数JSON使用网页同一制单参数，例如 `{"contractNo":"EXP990001","spotRate":6.8,"documentDate":"2026-11-16"}`（均为合成示例）；单票时可省略合同号，无覆盖参数时可省略 `--options`。输出不得已存在，文件权限为0600；成功后仅打印表数/行数。此入口复用网页的价格记忆和完整性校验，不写业务库。人工单价仍按既有规则保存到私有报价记录。

订单/仓库取数入口为「订单详情 → 单证 → 生成出口四单」，复用现有数据库预检及归档接口；无需另建一套导出逻辑。

报价规则已统一：单价（USD）= 单位采购成本 ¥ × (1 + 加价) ÷ (现汇 − 0.2)，按美元价位分档就近取整（例1993.87→2000、6.50→6.5）；老商品默认取上次确认价，新商品才用此公式，普通商品加价 30%、瓷砖等分类按 设置 > 报价规则 单独设置；
缺采购成本时不给建议价，需人工填写。详见 `docs/redesign/UX-REDESIGN-2026.md` §7.2 与 `docs/operations/export-pricing.md`。
退税率查询、数据完整性检查等其余步骤不变。

- 「数量」与「报关数量」映射同一字段；两列同时出现且冲突时停止。
- 合同号只去首尾空格、统一大小写，不自动增删零，不按柜名替代EXP选票。
- 「捷淞」或公司完整名称进入本方四单；「其他厂家报关」「不报关」「埋单」作为排除项在界面显示，未知或空白报关归属不能静默处理。
- 保留源数量、单位、规格、箱数、毛净重、体积；不把规格默认解释成每箱尺寸并重算体积。
- 公式只读已保存结果，无缓存或Excel错误要求重新计算保存；不执行任意公式。
- 同名记录保持分行和源顺序。只有已确认的品名/规格档案可补HS、要素和货源地；匹配不唯一时要求补证，不做模糊猜测。
- 人工出口价列支持：`出口单价(USD)`、`出口单价（USD）`、`美元单价`、`出口单价`。采购金额按人民币成本处理，不能当作美元售价。

限制：XLSX最大10MB，展开不超过60MB，明细最多5000行，每票最多500行。其他布局不冒充可解析文件。

## 定价顺序和约束

1. 使用本票人工价或Excel已有出口价。
2. 无人工价时查最近同品名、同规格历史报价；本票已保存的人工确认价同样可复用，未确认的本票历史不作参考。
3. 已确认的人工历史价优先保留，偏离当前分类/默认加价目标超过5个百分点时提示复核；普通历史参考价不满足此范围时不自动沿用。
4. 无可靠历史价时复用 `exportPricing.priceFor()`，读取「设置 → 报价规则」中的汇率调整与分类/默认加价，美元单价分档就近取整。
5. Excel已有价或本票人工覆盖优先保留；偏离目标在界面提示。HS、税库、数量和成本等缺项仍阻止生成。
6. 原模板行金额使用 `ROUNDUP(数量×单价,1)`，页面合计与四单缓存、公式一致。
7. 成功生成时，将人工单价按品名、规格、门店和合同号写入私有报价记录；自动建议价不记为人工确认。下次同品名、同规格优先匹配同门店的最近记录；未区分门店的同批历史出现多个价格时不猜测，并复核当前成本和汇率。

现汇使用现有系统公开汇率查询，失败时填写本票现汇，不暗用示例6.8或旧票汇率。税库按出货日期（缺失时按单证日期）选择生效记录，并核对税务局当前发布版本；版本变化或查询失败时不自动放行。

## 通用取整规则（已确认）

按原始美元单价选择步长，就近取到该步长的倍数：

| 原始单价 | 步长 |
|---|---:|
| 0＜单价＜10 | 0.5 |
| 10≤单价＜100 | 5 |
| 100≤单价＜5000 | 50 |
| 单价≥5000 | 1000 |

距离相等时向上取；正数最低报价0.5美元，避免产生零售价。取整后实际成本加价率偏离分类/默认目标超过5个百分点时提示复核，不阻止生成。人工价和已确认历史价不重新取整，已有订单和四单不重算。单价取整规则不会复现每一次人工谈价，本票最终价独立保留。

## 两种利润率

销售额CNY = 四单总额USD × 调整汇率。价差 = 销售额CNY − 采购成本CNY。

- 成本加价率 = 价差÷采购成本。
- 销售毛利率 = 价差÷销售额。
- 毛利率 = 加价率÷（1＋加价率）。例如成本100、售价130，加价30%，毛利率23.08%。

分母不同，不代表少赚一笔钱。此价差测算未计退税、运费、报关费、银行手续费和汇兑变化，不能称为最终净利润。

## 一次性保存模板与资料

管理员在后端目录运行：

```bash
node scripts/setup-export-packet.js \
  --template '/path/to/已确认合同发票箱单.xlsx' \
  --catalog '/path/to/申报要素目录.xlsx' \
  --refund-dbf '/path/to/cmcode.dbf' \
  --refund-version 2026C \
  --reviewed-on 2026-11-14
```

日期和版本为参数示例，维护时使用实际核对结果。安装器提取已确认的买卖方、条款、商品申报资料和历史单价，清除模板票号、日期和商品金额，形成可复用模板。银行信息、报价和真实商品资料不写入源码、工程记忆或Git。

配置位于实际 `UPLOAD_DIR/export-packet/profile.json`，目录0700、文件0600；覆盖前备份。配置不通过通用系统设置接口返回。发布时须经可信通道放入服务器实际上传根目录，不能只发源码就声称模板可用。

已有三页私有模板可直接升级为四单输出，不必重新安装公司资料；固定预录页由共享生成器添加。

新增确认商品/规格或新税库时重新运行安装器。生成的人工价保存为同目录下不可覆盖的 `quotes-<hash>.json`（0600），重复下载不重复写入；不改变业务库商品和订单。历史单价用于此 Excel 制单流程。

## 实现与验收

- 解析、版本校验、私有配置、原模板生成：`backend/src/services/exportPacketExcelService.js`。
- 共享定价与利润口径：`backend/src/services/exportPacketService.js`。
- 固定预录页：`backend/src/services/customsPreentrySheet.js`；命令行入口：`backend/scripts/generate-export-packet.js`。
- HTTP：`POST /api/v1/sales/export-packet/excel/preview` 和 `/generate`，认证后仅ADMIN。
- 页面：出口列表的 `ExportPacketExcelDialog`。单票完整时自动下载，多票选择后生成；改参数后重新计算，关闭后不执行迟到下载。
- 验收覆盖：数量别名/冲突、公式缓存、他方货物、源行不拆、人工价保持、税库/汇率失败、四单一致、来源变化、超过16行的模板扩展、未登录/SALES拒绝、真实浏览器下载及手机操作。

旧 `scripts/prepare_export_packet.py` 已停用；网页复用系统唯一报价实现，不依赖本机WPS缓存路径。
