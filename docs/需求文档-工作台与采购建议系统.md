## 二、门店采购建议系统

### 2.1 业务场景
- 门店A已完成采购，其采购清单可作为"标准店铺配置"
- 新门店B需要采购，希望系统能给出建议：
  - 应该买哪些商品？
  - 每种商品应该买多少？

### 2.2 功能设计

#### 2.2.1 标准配置学习
- **数据来源**：已完成的出口合同（SalesContract）及其装箱明细（PackingItem）
- **按门店聚合**：统计每个门店购买的所有商品及数量
- **生成模板**：基于已有门店数据，生成"门店标准配置"

#### 2.2.2 采购建议生成
**输入**：
- 目标门店（新门店或已有门店）
- 参考门店（可选，默认使用所有门店的平均值）

**输出**：
- 建议采购的商品清单
- 每种商品的建议数量
- 参考依据（基于哪些门店的数据）

#### 2.2.3 界面设计
```
┌─────────────────────────────────────────────────────────┐
│                  门店采购建议                            │
├─────────────────────────────────────────────────────────┤
│  选择目标门店: [下拉选择/输入新门店名]                     │
│  参考门店:     [多选，默认全部]                           │
│  [生成建议]                                             │
├─────────────────────────────────────────────────────────┤
│  采购建议清单                                           │
│  ┌──────────────────────────────────────────────────┐  │
│  │ 商品名称    │ 建议数量 │ 参考均值 │ 参考来源        │  │
│  │ 餐桌        │ 50      │ 48.5    │ 门店A/B/C      │  │
│  │ 瓷砖        │ 300平   │ 285     │ 门店A/B        │  │
│  │ ...        │ ...     │ ...     │ ...           │  │
│  └──────────────────────────────────────────────────┘  │
│                                                         │
│  总计预估金额: $XX,XXX                                   │
│  [导出清单] [一键创建采购单]                              │
└─────────────────────────────────────────────────────────┘
```

### 2.3 算法逻辑

```
1. 获取参考门店列表
2. 对每个参考门店，统计其所有已完成合同的商品采购情况
3. 聚合计算：
   - 商品出现频率（有多少门店购买过）
   - 平均采购数量
   - 最小/最大采购数量
4. 生成建议：
   - 高频商品（>50%门店购买）=> 强烈建议
   - 中频商品（20-50%门店购买）=> 一般建议
   - 低频商品（<20%门店购买）=> 可选
5. 数量建议：使用中位数或平均数
```
